O que é Scratch?

Scratch é uma ferramenta para aprender a programar de um jeito visual. Em vez de escrever um monte de código, você encaixa blocos, como se estivesse montando peças de LEGO. Cada bloco dá uma instrução para o personagem, como andar, falar, mudar de lugar ou fazer alguma coisa acontecer.

Será que minha idade é compatível?

Sim! O Scratch foi criado principalmente para crianças e adolescentes, e pode ser aprendido a partir dos 8 anos com bastante facilidade. Mas não existe uma idade máxima: qualquer pessoa pode usar a ferramenta para aprender lógica e programação. Na oficina, vamos começar do zero, então você não precisa chegar sabendo programar.

Como isso vai me ajudar se eu quiser ser programador(a) um dia?

Programar é um pouco como ensinar uma receita para o computador: você precisa explicar cada passo na ordem certa e pensar no que deve acontecer quando alguma coisa muda. O Scratch ajuda você a treinar justamente esse tipo de raciocínio.

Depois, quando você aprender linguagens como Python, JavaScript ou outras, vai encontrar ideias parecidas com as que aprendeu aqui. O Scratch não é um substituto para essas linguagens, mas é uma ótima maneira de começar a entender como a programação funciona.

Preciso saber alguma coisa antes?

Não! Você não precisa saber programar, entender de computadores ou ter feito um curso antes. Vamos começar pelas coisas mais simples e construir o projeto juntos, passo a passo.

É muito difícil?

Não precisa se preocupar. No começo, programar pode parecer como aprender a montar um brinquedo novo: você olha para várias peças e ainda não sabe exatamente onde cada uma vai. Aos poucos, você entende para que serve cada peça e começa a montar suas próprias ideias.

E errar faz parte! Se o personagem fizer alguma coisa diferente do que você esperava, isso não significa que você fez tudo errado. É só uma pista para descobrir o que precisa mudar.

Tenho que pagar alguma coisa?

Não! A oficina é gratuita e faz parte de um projeto dentro da escola. Para participar, é só se matricular avisando o professor Carlos ou procurando a secretaria da escola.

Vou ganhar um certificado?

Sim! Ao participar da oficina, você receberá um certificado digital. Ele poderá ser colocado no seu LinkedIn, que é como um currículo na internet onde as pessoas podem mostrar seus estudos, projetos e experiências.

E você também poderá publicar ou guardar o certificado onde quiser.
